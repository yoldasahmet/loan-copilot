# Security policy

SME Loan Copilot is a portfolio project, not a hosted service. There is no production deployment and no real client data.

If you find a vulnerability in the code (for example a way around the per-case access control, the pseudonymisation or the upload checks), please report it privately through GitHub's **Report a vulnerability** button on the repository's Security tab, not in a public issue. Include the steps to reproduce it and the commit you tested.

Never put real personal or financial data in a report; the synthetic demo data is enough to show a problem.
